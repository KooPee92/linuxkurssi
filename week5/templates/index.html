Local AI Assistant

This chatbot runs on my own Linux server using Ollama and the Qwen2.5 3B language model.

Conversations are stored in MariaDB. Please do not enter sensitive information.

Project Information

The application uses Flask, Gunicorn, Ollama and MariaDB.

The language model runs locally on this server. Conversation history is loaded from MariaDB when the page is refreshed.
